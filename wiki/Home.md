# Gamelist Media Editor — Wiki

Bienvenue sur la documentation de **Gamelist Media Editor**, un outil local pour éditer les médias et métadonnées d’un fichier `gamelist.xml` (RetroBat / EmulationStation).

## En deux mots

Application web **locale** (sur ton PC uniquement) qui te permet de :

- glisser-déposer images, vidéos, marquees, manuels et jaquettes ;
- renommer un jeu, éditer sa description ;
- modifier genre, note, développeur, langue, etc. ;
- purger les balises `<region>` ;
- supprimer complètement un jeu (ROM + médias + entrée XML).

Tout est sauvegardé **directement** dans ton `gamelist.xml`. Aucun compte, aucun cloud.

## Pour qui ?

Conçu pour les collectionneurs **RetroBat** / **EmulationStation** qui veulent finaliser proprement les jeux mal scrapés, sans éditer le XML à la main.

Accessible aux débutants : double-clic sur `Lancer.bat` sous Windows, puis glisser-déposer dans le navigateur.
