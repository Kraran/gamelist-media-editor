# Gamelist Media Editor — Wiki

**Version documentée : 1.3.0**

## En deux mots

Application web **locale** (sur ton PC uniquement) qui te permet de :

- glisser-déposer **image, vidéo, marquee, manuel, boxback, support, boxart, fanart, mix, maps** ;
- **scraper** un jeu via **ScreenScraper**, **Arcade Database** ou **Steam** (champ par champ) ;
- filtrer les jeux **sans média** ;
- éditer nom, description, genre, note, région, système arcade, favori / caché / jeu enfant ;
- **changer la langue** de l’interface (13 langues) ;
- **ouvrir un autre `gamelist.xml`** sans redémarrer ;
- sauvegarder un `.bak`, purger `<region>`, supprimer un jeu (ROM + médias + XML) ;
- quitter proprement (**⏻ Quitter**).

Tout est écrit **directement** dans ton `gamelist.xml`. Aucun cloud obligatoire (sauf si tu lances un scrape).

## Installation rapide (Windows)

1. Télécharge **`GamelistMediaEditor-Windows-v1.3.0.zip`** sur la [release v1.3.0](https://github.com/Kraran/gamelist-media-editor/releases/tag/v1.3.0)
2. Dézippe → double-clic sur **`GamelistMediaEditor.exe`**
3. Une fenêtre application s’ouvre (sans barre d’adresse si Edge / Chrome / Brave est dispo)
4. **📂 Gamelist…** pour ouvrir ton `gamelist.xml`

Optionnel : glisse un `gamelist.xml` sur le `.exe`.

Source Python : voir [Installation](Installation).
