# Gamelist Media Editor — Wiki

**Version documentée : 1.4.0**

## En deux mots

Application web **locale** (sur ton PC uniquement) qui te permet de :

- glisser-déposer **image, vidéo, marquee, manuel, boxback, support, boxart, fanart, mix, maps** ;
- **scraper** un jeu avec un seul bouton (**ScreenScraper**, **Arcade Database** ou **Steam** selon le système) et **comparer** l’actuel et le proposé avant d’appliquer ;
- voir d’un coup d’œil ce qui manque (**miniatures** et **compteur de médias** dans la liste, filtre par média manquant, **Suivant incomplet**) ;
- éditer nom, description, genre, note (étoiles), date, langue, région, système arcade, favori / caché / jeu enfant, avec **une seule barre d’enregistrement** ;
- travailler au **clavier** (`J`/`K`, `N`, `S`, `Ctrl+S`…) ;
- **ouvrir un autre `gamelist.xml`** sans redémarrer, en **13 langues**.

Tout est écrit **directement** dans ton `gamelist.xml`. Aucun cloud obligatoire (sauf pendant un scrape).

## Installation rapide (Windows)

1. Télécharge **`GamelistMediaEditor-Windows-v1.4.0.zip`** sur la [release v1.4.0](https://github.com/Kraran/gamelist-media-editor/releases/tag/v1.4.0)
2. Dézippe → double-clic sur **`GamelistMediaEditor.exe`**
3. Une fenêtre application s’ouvre (sans barre d’adresse si Edge / Chrome / Brave est dispo)
4. **Gamelist…** pour ouvrir ton `gamelist.xml`

Optionnel : glisse un `gamelist.xml` sur le `.exe`.

Source Python : voir [Installation](Installation).
