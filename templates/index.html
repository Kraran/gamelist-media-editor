À propos

Gamelist Media Editor

v{{ app_version }}

Application web locale pour éditer les médias et métadonnées d’un gamelist.xml EmulationStation / RetroBat. Glisser-déposer, scrapers ScreenScraper & Arcade Database, filtres, sauvegarde et interface multilingue.

{{ icon("settings") }}Réglages

Langue de l’interface

Change la langue de l’interface. Le choix est mémorisé sur ce navigateur.

ScreenScraper

Le scrape fonctionne immédiatement (identifiants logiciel intégrés). Optionnel : ton compte membre pour le boost de quotas. Stocké en local dans screenscraper_config.json.

Source de scrape par système

Le bouton Scraper choisit la source selon le système : Arcade Database pour les dossiers arcade, Steam pour steam, ScreenScraper pour les autres. Un autre choix fait dans son menu est retenu ici, sur ce navigateur.
