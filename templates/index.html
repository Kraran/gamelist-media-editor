À propos

Gamelist Media Editor

v{{ app_version }}

Application web locale pour éditer les médias et métadonnées d’un gamelist.xml EmulationStation / RetroBat. Glisser-déposer, scrapers ScreenScraper, Arcade Database & Steam, filtres, sauvegarde et interface multilingue.

ScreenScraper

Le scrape fonctionne immédiatement (identifiants logiciel intégrés). Optionnel : ton compte membre pour le boost de quotas. Stocké en local dans screenscraper_config.json.

Rescraper un jeu déjà trouvé ne consomme alors aucune requête de ton quota.

Source de scrape par système

Le bouton Scraper choisit la source selon le système : Arcade Database pour les dossiers arcade, Steam pour steam, ScreenScraper pour les autres. Un autre choix fait dans son menu est retenu ici.

Médias requis par système

Un jeu est complet quand il a tous les médias requis de son système. Le compteur de la liste, le filtre « Média requis manquant » et Suivant incomplet s’en servent.
