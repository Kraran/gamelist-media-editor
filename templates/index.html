À propos

Gamelist Media Editor

v{{ app_version }}

Application web locale pour éditer les médias et métadonnées d’un gamelist.xml EmulationStation / RetroBat. Glisser-déposer, scrapers ScreenScraper & Arcade Database, filtres, sauvegarde et interface multilingue.

Techno
Python, Flask, lxml, HTML/JS
Logiciel fourni « tel quel ». Aucune ROM n’est distribuée. Les scrapers accèdent aux services publics ScreenScraper et Arcade Database (Arcade Italia) — utilisez-les de façon raisonnable.

{{ icon("adjustments-horizontal") }}Outils

Actions globales sur le fichier gamelist.xml (pas liées à un jeu précis).

{{ icon("language") }}Langue de l’interface
Change la langue de l’interface. Le choix est mémorisé sur ce navigateur.
{{ icon("cloud-download") }}ScreenScraper
Le scrape fonctionne immédiatement (identifiants logiciel intégrés). Optionnel : ton compte membre pour le boost de quotas. Stocké en local dans screenscraper_config.json.
{{ icon("cpu") }}Remplir les systèmes arcade
Lit un dump MAME mame.xml (mame.exe -listxml) et écrit <arcadesystemname> (CPS2, Neo-Geo…).
{{ icon("device-floppy") }}Sauvegarder le gamelist.xml
Crée une copie gamelist.xml.bak à côté du fichier courant. Écrase l’ancien .bak s’il existe.
{{ icon("eraser") }}Supprimer toutes les balises <region>
Retire toutes les lignes <region>…</region> de tous les jeux. Confirmation demandée (sauvegarde .bak optionnelle).
